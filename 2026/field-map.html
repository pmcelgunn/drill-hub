Setup Order

Paint before cones — these lines never move all season

1 · Speed lane (paint first)

One straight 40-yard line. Hash marks at 0, 10, 20, 30, 40. This is the longest, straightest reference on the field — every other station's spacing gets paced off this line, so it has to go down first while the wheel is fresh and the string line is taut.

2 · Jump box (paint second)

Takeoff line, then the 10-foot runout marked every 6 inches. Do this right after the lane while the wheel is still out and calibrated — no need to re-measure from scratch.

3 · Agility 5-10-5 (paint third)

Center line connecting the three cone spots, 5 yards apart. This is the smallest and quickest of the three painted lines, so it's last — easy to true up in the few minutes before check-in.

4 · Cones — Stations 2, 3, 4

The mirror box, hands marks, and arm/mesh gates all scale by age group and aren't painted — set these with cones only, using the wheel off the painted lane/lines already down.

5 · Check-in table & water/gear

One table at the parking-lot end with the check-in sheet, printed score cards, pens, and the relay pinnies. Water/gear spot opposite it, same end of the field.

6 · Leave the middle empty

Don't set a single cone in the center. That's the bracket field at 7:18 — if steps 1-5 land in the right spots around the outside, the middle is already correct and nobody touches a cone to run the bracket.

A takeoff line, plus a measuring line running 10 feet out from it, marked every 6 inches.

Center line connecting three cone spots set 5 yards apart (10 yards end to end).
